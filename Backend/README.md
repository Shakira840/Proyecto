# Habits Tracker Backend

Este es el backend de **Habits Tracker**, un proyecto desarrollado con **Node.js** y **Express.js** para gestionar hábitos mediante una API REST.

## 📌 Requisitos

Antes de ejecutar el proyecto, asegúrate de tener instalado:

- [Node.js](https://nodejs.org/)
- [MongoDB](https://www.mongodb.com/)

## 🚀 Instalación y Ejecución

1. **Clonar el repositorio**  
   ```sh
   git clone https://github.com/Shakira840/Proyecto.git
   cd Proyecto

2. **Instalar dependencias**
   npm install

3. **Configurar variables de entorno**
   

4. **Iniciar el servidor**
   npm start
   El servidor se ejecutará en

   ## 📌 Tecnologías Usadas
    Node.js y Express.js - Framework para backend
    MongoDB - Base de datos NoSQL
    Mongoose - ODM para MongoDB
    Dotenv - Manejo de variables de entorno
    Cors - Configuración de seguridad para peticiones externas
